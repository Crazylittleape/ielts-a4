# 2026-10-25 · 简约学习工具：批量加入复习、错词记录、复习密度

## 改动前的语义（基线 1cd2762）

- `answerBookQuestion` 完成一组时，为本组所有新词创建 `WordItem` 和 FSRS 卡，次日起全部进入“全部到期复习”。
- `focusBookWord` 只控制 A4 攻坚（`focus.active`），和“是否进入复习”是两个开关。
- 组完成页和学习卡上有逐词“加入 A4”按钮；错词只存在 `BookView` 组件内存（`missed`），刷新即丢失。
- 调度器是模块级 `fsrs({ enable_short_term: false, enable_fuzz: false })`，期望保留率为 ts-fsrs 默认 0.9。

## 本轮规则

1. 学完一组：本组词仍写入同一个 `WordItem`（已学、可查词、可自由练习），词书进度照常计入；新建的词带可选字段 `review: 'off'`，不进入任何复习任务。
2. 只有用户在组完成页一键选择的词进入复习：按钮为“本组错词 N 词”“本组全部 N 词”，点按前不写入。选中的词同时进入 A4 攻坚。默认选项（`settings.groupPick`，默认错词）在“学习设置”里改，也会记住上次在组完成页的选择。
3. 补加入口只有两个：已完成组回看页的同一组批量按钮；“我的单词”里用搜索/来源/“未加入复习”筛选缩小范围后，点“将筛选出的 N 个未复习词加入复习”。没有任何逐词“加入”按钮。保留逐词“移出 A4”（纠错用，当天撤销会恢复为未加入复习）。
4. `review: 'off'` 在底层排除：`isDueOn` 返回 false，`buildSchedule`/`buildCalendar` 跳过，因此个人日历、到期数、首页下一步、全部复习、A4、看板一致排除；`gradeWord` 对其不生效。缺字段（旧数据）= 在复习中，旧排期不动。
5. 批量加入（`joinReview` / `joinGroupReview`）一次构造新状态、一次 `commit` 原子保存，按词 id 去重：
   - off → on：用原卡（`addToFocus`），首次到期 = 明天，卡片稳定性/难度不变，不写日志；当天撤销恢复 off。
   - 已在复习（无 `review` 字段）：卡片、到期日不变，只加入 A4，`focus.nextDate` = 原到期日，不写日志。
   - 已在 A4：不变；已标记掌握：不变。
   - 结果文字区分：0 错词、全部已在复习、部分已在复习、新加入数量；保存失败不显示成功。
   - 组内词若已在“我的单词”里被删除，批量加入时按词书数据重建（同样从明天开始）。
6. 错词持久化在 `bookLearning.missed[groupId]`：`beginGroup` 时建空数组，任一轮回忆“没想起来”、拼写错误/空答案即记录，去重，重练答对不移除。随 IndexedDB、JSON 备份、恢复、合并（并集）保留；备份校验要求组存在、已完成或进行中、词属于该组、不重复。没有该字段的旧组显示“历史错词记录不可用”，错词按钮禁用，不当作 0。
7. 复习密度 `settings.density`：轻松 / 标准 / 强化 → ts-fsrs `request_retention` 0.85 / 0.90 / 0.95（ts-fsrs 5.4.2，合法范围 0 < r ≤ 1，默认 0.9）。期望保留率越高，间隔越短。标准与旧调度参数完全一致；缺字段 = 标准。只影响之后的评分，不重排已有卡片和日志。非法值在备份导入和设置保存时拒绝。以默认 0.90 为中心各取 ±0.05：三档都在合法范围内，固定样本测试中已产生不同间隔（见 `src/review.test.ts`）。
