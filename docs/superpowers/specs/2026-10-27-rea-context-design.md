## A · 内容、学习页、复习结果

- 例句：`app/src/data/book-examples.json` 收录前 200 词中 197 词的 Tatoeba 句子（135 条带中文），来源与覆盖见 `docs/EXAMPLES-SOURCE.md`。全书覆盖 197/3630。
- `exampleFor(word)`：用户自己的例句优先，否则按词头只读回退到词书例句；不改写 WordItem、卡片、日期或日志，旧词也能看到。
- `highlightParts(sentence, word)`：整词、不区分大小写，边界不含字母/数字/连字符；支持原形、+s/+es/+ed/+d/+ing、y→ies/ied、去 e+ing、-ise/-ize；多词词条只变最后一个词。单测覆盖 `ore`/`more`、`core`/`scored`、`mantle`/`dismantle` 等边界；每条收录例句都至少命中一次（单测校验）。
- 学习页：顶部只有返回和“第 n/3 轮 · x/25”；中间一张词卡；底部固定一个主操作区。三轮题型、揭示时机、轮末重练、拼写检查后继续、断点恢复不变。例句只在回忆题揭示答案后、拼写题检查后出现（直接展开一条，含高亮、朗读、来源）；揭示前不出现例句、高亮或带答案的朗读标签。
- 复习结果：A4 今日页在有已保存评分时显示“今日复习结果”：已复习 N 词、其中忘记/困难的词、每词评分与实际下次日期、“还有 K 词未评分，仍在今日待复习”。只读取已持久化的 revlog（当天、当前列表内的词），保存失败不会出现，刷新后一致。评分按钮旁加一句选择说明，四档 FSRS 不变。状态文字区分“本组初学完成 / 已加入复习 / 今日复习完成 / 已标记掌握”。

## B · 壁纸、打印

- 自定义壁纸时加柔和遮罩，阅读面（词卡、A4 纸面、卡片）保持不透明，深浅图片都可读。压缩、离线、恢复默认、错误保留原图不变。
- A4 工具栏“打印 / 另存 PDF”：选项框（显示英文 / 显示中文，至少一项）后调用浏览器 `window.print()`。打印内容只是当前查看的日期 + 范围列表（不导出全书）。`@page size: A4; margin: 12mm`，页眉词书/范围/日期/词数，两栏，隐藏栏留书写横线，行不跨页，Chromium 显示页码（WebKit 不支持页边距盒，只有页脚文字）。屏幕界面在打印时隐藏。打印不写评分、日志或完成状态（E2E 校验快照不变）。
- 看板：未改日历模型；结果面板数字与看板今日计数一致（E2E）。
